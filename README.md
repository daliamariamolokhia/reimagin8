# reimagin8

Premium strategy, innovation, and leadership advisory website.

## Development

```bash
cd site
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Brand colours (from workshop deck)

| Token | Hex | Usage |
|-------|-----|-------|
| Navy | `#1A2B4A` | Primary dark, headers, footer |
| Coral | `#FF6B35` | Accent, CTAs, highlights |
| Sky | `#5DA9E9` | Secondary accent, links |
| Slate | `#8B95AB` | Body text, muted labels |

## Pages

- **Home** — Hero, services overview, featured workshop, approach, CTA
- **Services** — Strategy, Innovation, Design, Leadership
- **Approach** — Diagnose → Design → Deliver → Develop
- **Workshops** — The Growth Gap, Level Up Leadership
- **Contact** — Enquiry form
